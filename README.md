# Claude SEO + AEO + GEO Audit Agent

An AI-powered website auditing framework designed to work with Claude Code.

## What it does

The system can analyze:

- Technical SEO
- On-page SEO
- Content
- Structured data
- AEO
- GEO
- AI citation opportunities

## How it works

Website URL
↓
Crawler
↓
Website data
↓
SEO analysis
↓
AEO analysis
↓
GEO analysis
↓
Claude analysis
↓
Final audit report

## Usage

Open the repository using Claude Code.

Then provide a website URL.

Example:

Audit https://example.com

Claude will follow the instructions in CLAUDE.md,
run the available audit scripts and generate the report.

## Important

The audit provides recommendations and diagnostic analysis.

It does not guarantee:

- Google rankings
- AI Overview inclusion
- ChatGPT citations
- Perplexity citations
- Gemini citations
